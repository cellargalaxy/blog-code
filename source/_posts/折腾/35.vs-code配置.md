## 插件

+ Chinese (Simplified) (简体中文) Language Pack for Visual Studio Code
+ Code Runner：在文件树（Explorer）里右键某个文件直接执行
+ Remote Development
+ IntelliJ Code Formatter
+ IntelliJ IDEA Keybindings
+ JetBrains Icon Theme
+ JetBrains New UI Dark Theme

## 配置

+ 按 Ctrl + Shift + P (Windows/Linux) 或 Cmd + Shift + P (Mac) 打开命令面板
+ 输入并选择 “首选项: 打开设置 (JSON)” (Preferences: Open Settings (JSON))
+ 在打开的 settings.json 文件中，添加或修改以下配置项

```
{
  // ========== 自动保存 ==========
  "files.autoSave": "afterDelay", // 编辑后自动保存
  "files.autoSaveDelay": 1000, // 自动保存延迟
  // ========== 编辑器滚动与边距 ==========
  "editor.padding.bottom": 60, // 最后一行代码距离底边框60px
  "editor.scrollBeyondLastLine": false, // 禁止滚动超过最后一行，让最后一行停在底部
  "editor.minimap.enabled": false, // 隐藏代码预览
  // ========== 文件树行为 ==========
  "workbench.tree.expandMode": "doubleClick", // 单击文件夹，只是选中，不要展开文件夹
  "workbench.tree.indent": 20, // 文件树的缩进长度
  "explorer.compactFolders": false, // 当一个文件夹下只有一个文件夹时，每一层都独立显示
  // ========== 文件打开方式 ==========
  "workbench.list.openMode": "doubleClick", // 双击打开文件
  "workbench.editor.enablePreview": false,
  "window.openFilesInNewWindow": "on", // 双击文件时，强制在新窗口打开
  // ========== 主题与图标 ==========
  "workbench.colorTheme": "JetBrains New UI Dark Theme",
  "workbench.iconTheme": "vscode-jetbrains-icon-theme-2023-dark",
  // ========== 字体与缩放==========
  "editor.fontFamily": "'JetBrains Mono', Consolas, 'Courier New', monospace",
  "editor.fontSize": 13, // 基础字号降低，配合整体缩放后大小更合适
  "editor.lineHeight": 24, // 行高适中（约 1.85 倍），避免放大后扁平
  "editor.letterSpacing": 0.4, // 字距稍收，放大后不会显得过散
  "editor.fontWeight": "400", // Regular
  "editor.fontLigatures": true, // 开启连字
  "terminal.integrated.fontFamily": "'JetBrains Mono', monospace",
  "terminal.integrated.fontSize": 13, // 终端基础字号同步降低
  "terminal.integrated.lineHeight": 1.5,
  "window.zoomLevel": 1 // 整体 UI 放大一级
}
```
