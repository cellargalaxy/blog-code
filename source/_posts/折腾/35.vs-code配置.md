+ 配置
+ 按 Ctrl + Shift + P (Windows/Linux) 或 Cmd + Shift + P (Mac) 打开命令面板
+ 输入并选择 “首选项: 打开设置 (JSON)” (Preferences: Open Settings (JSON))
+ 在打开的 settings.json 文件中，添加或修改以下配置项

```json
{
  // 设置自动保存模式，例如 "afterDelay"
  "files.autoSave": "afterDelay",
  // 设置延迟时间，单位为毫秒，1000 即 1 秒
  "files.autoSaveDelay": 1000,
  // 最后一行代码距离底边框 60px
  "editor.padding.bottom": 60,
  // 设置为 false，禁止滚动超过最后一行，让最后一行停在底部
  "editor.scrollBeyondLastLine": false,
  // 左侧文件树，单击文件夹，只是选中，不要展开文件夹
  "workbench.tree.expandMode": "doubleClick",
  // 左侧文件树的缩进长度
  "workbench.tree.indent": 20,
  // 文件树，当一个文件夹下只有一个文件夹时，每一层都独立显示
  "explorer.compactFolders": false,
  // 1. 双击打开文件（关闭单击预览）
  "workbench.list.openMode": "doubleClick",
  "workbench.editor.enablePreview": false,
  // 2. 双击文件时，强制在新窗口打开
  "window.openFilesInNewWindow": "on",
  // 编辑器代码字体大小（补偿缩放后的效果）
  "editor.fontSize": 14,
  // 整体 UI 缩放（正数放大，负数缩小，默认 0）
  "window.zoomLevel": 1,
  // 可选：终端字体
  "terminal.integrated.fontSize": 14
}
```
