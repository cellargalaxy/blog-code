## 背景提要

+ 本来是计划WSL实现Windows与Linux双持的，但是奈何WSL的BUG是在太多，且内存占用大，空转都能占用3G内存，放弃该方案
    + [32.WSL安装.md](32.WSL%E5%AE%89%E8%A3%85.md)
+ 安装双系统，Windows的抽风更新我担心会破坏Linux，不推荐
+ 最后只剩下Linux作为宿主机，在Linux里安装Windows虚拟机，且需要实现显卡直通


+ 首先安装Debian，[30.安装Debian手记.md](30.%E5%AE%89%E8%A3%85Debian%E6%89%8B%E8%AE%B0.md)其中关于N卡驱动先不操作

## 方案

+ 主系统是Debian13，不安装桌面，大部分时候使用的是Linux，通过SSH控制
+ Linux安装Docker，Docker再使用显卡，避免弄脏系统
+ 在Linux基础上，通过KVM虚拟机+PCI显卡直通，部署Windows11物联网版虚拟机
+ KVM负责运行虚拟机，libvirt负责调度虚拟机，cockpit负责界面化管理

## BIOS检查

+ 如果找不到`Above 4G Decoding`，直通大概率失败，建议直接转 Plan B（Debian 原生跑 DaVinci Resolve）。

| 项目	                                    | 设置        | 	说明      |
|----------------------------------------|-----------|----------|
| Intel Virtualization Technology (VT-x) | 	Enabled	 | CPU虚拟化   |
| VT-d / Intel VT for Directed I/O	      | Enabled   | 	显卡直通    |
| Above 4G Decoding	                     | Enabled	  | 显存映射     |
| CSM / Legacy Boot                      | 	Disabled | 	保持纯UEFI |

### 禁止休眠

```shell

sudo vim /etc/systemd/sleep.conf.d/nosuspend.conf
# 填写以下内容
[Sleep]
AllowSuspend=no
AllowHibernation=no
AllowSuspendThenHibernate=no
AllowHybridSleep=no

sudo systemctl restart systemd-logind
```

### 网络唤醒

```shell
sudo apt install -y ethtool
sudo ethtool enp3s0
# Supports Wake-on: g 表示支持网络唤醒
# Wake-on: d 表示当前未启用

# 需要将其启用为 g
sudo ethtool -s enp3s0 wol g

# 但是该命令只会生效一次，需要设置开机自动生效
sudo vim /etc/systemd/system/wol.service
[Unit]
Description=Enable Wake-on-LAN
After=network.target
[Service]
Type=oneshot
ExecStart=/sbin/ethtool -s enp3s0 wol g
[Install]
WantedBy=multi-user.target

sudo systemctl enable wol.service
```
